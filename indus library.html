System Information

Student Enrollment: Only the librarian can enroll students.


Book Management: Librarian can add books, specify the number of copies and edit existing books.


Book Issue: A book can be issued only when at least one copy is available.


HM Access: HM can view library records but cannot add students, add books, issue books or return books.
